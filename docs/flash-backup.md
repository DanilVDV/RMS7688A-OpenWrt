# SPI flash и резервные копии

Загрузчик: Ralink U-Boot 5.0.0.0, 115200 baud, bootdelay=5 (наблюдение в заводской среде). Физическая SPI NOR заявляет 64 МБ, но Linux MTD показывает **только первые 32 МБ**.

| Раздел | Размер | Назначение |
|---|---:|---|
| mtd0 | 0x00030000 (192 КиБ) | u-boot |
| mtd1 | 0x00010000 (64 КиБ) | u-boot-env |
| mtd2 | 0x00010000 (64 КиБ) | factory: Wi-Fi calibration/MAC |
| mtd3 | 0x01fb0000 (31.7 МиБ) | firmware |
| mtd4+ | вложенные | kernel, rootfs, rootfs_data |

Заводские backup-файлы имели размеры `196608`, `65536`, `65536`, `33226752` байт; их конкатенация — `33554432` байта (`flash_32MB.bin`). **Это не полный 64 МБ физический дамп.**

Пример создания резервных копий в безопасном каталоге с достаточным местом (перед использованием перепроверьте `/proc/mtd`):

```sh
cat /proc/mtd
mkdir -p /tmp/flash-backup
for n in 0 1 2 3; do
  dd if=/dev/mtd${n} of=/tmp/flash-backup/mtd${n}.bin bs=64k
done
sha256sum /tmp/flash-backup/*.bin
```

Немедленно перенесите файлы на workstation: `/tmp` находится в RAM. Не выкладывайте эти дампы в GitHub. При восстановлении загрузчика или factory ошибка может необратимо нарушить работу устройства.
