# UART / RS232 / LTE

На плате есть `/dev/ttyS0`, `/dev/ttyS1`, `/dev/ttyS2`. В кастомной сборке `ttyS2` освобождён от kernel console; точный патч ещё нужно сохранить в репозиторий. Перед подключением проверять уровни: GPIO/UART модуля 3,3 В, DB9 RS232 использует иные электрические уровни и требует трансивера.

План: сервис Python читает RS232, валидирует кадры и передаёт данные по сети. Формат протокола ещё не задан.

MT7688AN **не является LTE-модемом**. На carrier-плате есть SIM-слот, но неизвестно, к какому модемному интерфейсу он подключён. В заводской системе были драйверы QMI/MBIM/NCM/serial, однако модем `lsusb` не обнаруживал. Перед покупкой LTE-модуля необходимо проверить физический разъём, питание, USB-линии и SIM-разводку.
