# Аппаратная часть

Наблюдались: два RJ45 Ethernet, USB Host, micro-USB, слот microSD, DB9/RS232, клеммники, RTC-батарея, аудио MIC/PHONE, выводы GPIO/UART/SPI/I²C, слот с маркировкой SIM CARD. Расположение и назначение контактов требуют сверки с фотографиями и схемой.

USB hub: Terminus Technology `1a40:0801`. USB-накопитель: Phison `13fe:4300`.

MT7688AN сам по себе **не** LTE-модем. SIM-слот на carrier не доказывает, что к нему подведены линии внешнего модема. Не подключайте модем без проверки напряжений, интерфейса и SIM wiring.

Два RJ45 физически присутствуют; назначения портов, PHY и VLAN проверяйте в текущем DTS/`ip link`/`ubus`, а не по внешнему виду.
