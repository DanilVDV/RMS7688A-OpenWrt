# UART / RS232 / распиновка

На плате видны разъём DB9/RS232 и гребёнки с маркировкой UART/GPIO/SPI/I²C. В Linux обнаружены `ttyS0`, `ttyS1`, `ttyS2`. Ранее `ttyS2` использовался консолью (`console=ttyS2,57600`); в текущей кастомной прошивке он освобождён.

**Электрическая распиновка DB9 и соответствие разъёмов конкретным ttyS* пока НЕ подтверждены.** Не соединяйте напрямую уровни RS232 (двуполярные) с UART TTL (3.3 В). Для определения pin 1, TX, RX, GND, VCC и уровней требуется схема, маркировка микросхемы трансивера или измерения.

Команды диагностики:

```sh
ls -l /dev/ttyS*
cat /proc/cmdline
cat /proc/consoles
dmesg | grep -Ei 'ttyS|serial|uart'
```

План: подтвердить связь DB9 ↔ UART, установить `pyserial` в Python environment, написать сервис обработки входящих RS232-пакетов, настроить init/procd и watchdog. Протокол сообщений ещё не определён.
