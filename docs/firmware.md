# Актуальная стабильная прошивка

На 17 октября 2026 актуальная стабильная версия OpenWrt — **25.12.5** (Linux 6.12.94). [Страница релиза](https://openwrt.org/releases/25.12/notes-25.12.5).

Целевой профиль: `ramips/mt76x8`, `mediatek_linkit-smart-7688`, архитектура `mipsel_24kc`.

- [Каталог образов OpenWrt 25.12.5 для ramips/mt76x8](https://downloads.openwrt.org/releases/25.12.5/targets/ramips/mt76x8/)
- [Официальный Firmware Selector](https://firmware-selector.openwrt.org/)

**Осторожно:** официальный образ предназначен для LinkIt Smart 7688, а не специально для RMS7688A-DEMO. Он запускался на исследуемой плате, но не гарантирует работу всех периферийных устройств. Перед обновлением сверяйте модель, MTD и способ восстановления.

На OpenWrt 25.12 менеджер пакетов — `apk`; устаревшие инструкции с `opkg` здесь неприменимы.
