# SPI flash и резервное копирование

Загрузчик обнаружил физическую SPI NOR **64 МиБ**, однако Linux предоставил MTD-разделы только в первых **32 МиБ**:

| MTD | Название | Размер |
|---|---|---:|
| mtd0 | u-boot | 196608 байт |
| mtd1 | u-boot-env | 65536 байт |
| mtd2 | factory | 65536 байт |
| mtd3 | firmware | 33226752 байт |

Созданные локально файлы: `mtd0_u-boot.bin`, `mtd1_u-boot-env.bin`, `mtd2_factory.bin`, `mtd3_firmware.bin`, `flash_32MB.bin`. Последний — конкатенация mtd0–mtd3 (33554432 байта), **не дамп всей физической flash 64 МиБ**.

`factory` содержит критичные индивидуальные данные радиотракта. Не публиковать дампы. Восстановление через загрузчик выполнять только с проверенной схемой разделов и проверенными файлами.
