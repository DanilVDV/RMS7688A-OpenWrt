# RMS7688A-DEMO — OpenWrt 25.12.5

Практическая документация по плате **RMS7688A-DEMO** с модулем **RMS7688A / MediaTek MT7688AN**. Основана на реальных проверках одной платы. Это не официальный BSP производителя.

> **Статус:** Ethernet, Wi-Fi и USB extroot работают; I²C/RTC и microSD требуют дальнейшей диагностики; LTE-модем ещё не установлен. Не путайте наличие разъёма SIM с наличием сотового модема.

![Схема выводов эталонной платы LinkIt Smart 7688](https://statics3.seeedstudio.com/seeed/file/2017-08/bazaar537705_linkit_smart_7688_1.png)

*Иллюстрация относится к эталонной плате LinkIt Smart 7688, а не к RMS7688A-DEMO. Распиновку разъёмов RMS7688A-DEMO по ней определять нельзя. Источник: Seeed Studio.*

## Проверенная конфигурация

| Параметр | Значение |
|---|---|
| SoC | MediaTek MT7688AN, MIPS, 580 МГц |
| RAM | 256 МБ DDR2 |
| SPI NOR | физически 64 МБ, MTD описывает только первые 32 МБ |
| Исходная прошивка | OpenWrt 21.02-SNAPSHOT, Linux 5.4.171 |
| Установленная прошивка | OpenWrt 25.12.5, Linux 6.12.94 |
| OpenWrt target | `ramips/mt76x8`, `mipsel_24kc` |
| Профиль сборки | `mediatek_linkit-smart-7688` |
| Device tree compatible | `mediatek,linkit-smart-7688`, `mediatek,mt7628an-soc` |
| Система пакетов | `apk` |

**Важно:** выбранный профиль LinkIt Smart 7688 не является подтверждением полной электрической совместимости с carrier RMS7688A-DEMO. В частности, microSD и RTC пока не заработали.

## Безопасность

Не публикуйте дампы `factory`, `u-boot-env`, полный SPI flash, пароли, приватные ключи и конфигурацию сети. Перед прошивкой убедитесь, что есть резервная копия и рабочий способ восстановления через загрузчик. Никогда не прошивайте 64 МБ образ поверх 32 МБ MTD-разметки без проверки карты flash.
